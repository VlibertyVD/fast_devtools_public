FAST DEVTOOLS

Build faster. Click less.

The Problem

Developing in Odoo means constantly upgrading modules and switching debug modes to test your changes. Navigating away from your current view, going to the Apps menu, searching for your module, and clicking "Upgrade" breaks your focus. Typing ?debug=1 manually in the URL every time is just tedious.

The Solution

Fast DevTools brings these essential actions directly to your top navigation bar. Group your modules into custom update profiles and trigger cascading upgrades without ever leaving your current screen. Switch debug states with a single click. It's that simple.

Key Features

Smart Profile Updater

Create custom profiles like "Backend" or "Website" with specific dependencies. If you have only one active profile, the systray acts as an instant one-click updater. Multiple profiles? It elegantly drops down a selection menu.

Instant Debug Switcher

Toggle between Normal, Assets, and Tests debug modes instantly through a sleek dropdown menu. No more manual URL hacking when you need to inspect OWL components or clear caches.

How to Configure

  1. Go to Settings > General Settings.
  2. Scroll down to the Fast DevTools section.
  3. Select the debug modes you want to be visible in the menu.
  4. Enable the Updater and assign your pre-configured Update Profiles.
  5. Refresh and enjoy a faster workflow!
